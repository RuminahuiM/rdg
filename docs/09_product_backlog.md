# Product Backlog

## 1. Konventionen

### 1.1 Story-Format

```
### <STORY-CODE>: <Titel>
- **Key:** <PREFIX-n>
- **Als** <Rolle> **möchte ich** <Funktion> **damit** <Nutzen>
- **Akzeptanzkriterien:**
  - AC-1: ...
  - AC-2: ...
- **Bezug:** UC-x / FR-x / NFR-x
- **Abhängigkeiten:** blockedBy ...
- **ADRs:** <ADR-NNN, die gelten oder entstehen>
- **Schätzung:** <T-Shirt> / <SP>
- **Priorität:** Must / Should / Could / Won't
- **Sprint:** <n>
```

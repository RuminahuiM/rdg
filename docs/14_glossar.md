# Glossar

> Wird laufend gepflegt, im Doku-Chat Pflicht nach jedem Abschnitt. Alphabetisch sortiert. Wird als Anhang in den Schlussbericht übernommen.

| Begriff | Erklärung | Erstmals verwendet in |
|---|---|---|
| Acceptance Criteria (AC) | Prüfbare Bedingungen, die eine Story fachlich erfüllen muss | Backlog |
| ADR | Architecture Decision Record: kurze Dokumentation einer Architekturentscheidung mit Kontext, Optionen, Entscheidung und Konsequenzen | docs/adr |
| Definition of Done (DoD) | Projektweite Qualitäts-Checkliste, die jede Story erfüllen muss | Scrum-Setup |
| Definition of Ready (DoR) | Bedingungen, damit eine Story in einen Sprint aufgenommen werden kann | Scrum-Setup |
| Increment | Summe aller fertigen Backlog-Items eines Sprints, potenziell auslieferbar | Scrum-Setup |
| Sprint | Feste Zeitbox, in der ein Increment entsteht | Scrum-Setup |

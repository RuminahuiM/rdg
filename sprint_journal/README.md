# Sprint-Journal

- `_templates/` enthält alle Vorlagen (Planning, Daily, Review, Retro, Mentor-Termin, Evidence, Demo).
- Pro Sprint ein Ordner `sprint_<N>/` mit `01_planning.md`, `02_daily_journal.md`, `03_review.md`, `04_retrospective.md` sowie `evidence/` und `demos/`.
- `mentor_meetings/` sammelt die Mentor-Termine, getrennt von den Scrum-Events.

Ablauf und Pflichtpunkte: `harness/workflows/sprint_events.md`.
Bewertungsbezug: Fortschrittsüberwachung (Handlungskompetenz B5.9) und Datengrundlage für die Reflexion (Kriterium 5).
